# 📊 SoftITo - Veri Analitiği Eğitimi & Projeler

Bu depo, **İstanbul Ticaret Odası** öncülüğünde yürütülen **SoftITo Yazılım-Bilişim Akademisi** bünyesindeki Veri Analitiği eğitimi süresince tutulan haftalık ders notlarını, uygulamalı alıştırmaları, veri analiz çalışmalarını ve mini projeleri içermektedir.

---

## 🎯 Deponun Amacı

* Veri işleme, temizleme, görselleştirme ve analiz süreçlerinde edinilen teorik ve pratik bilgileri düzenli bir dokümantasyon haline getirmek.
* Gerçek dünya senaryolarına dayalı veri setleri üzerinde yapılan analiz ve problem çözme süreçlerini uçtan uca kayıt altına almak.
* Git ve GitHub pratiklerini aktif kullanarak sektörel standartlarda bir portfolyo oluşturmak.

---

## 🛠️ Kullanılan Teknolojiler & Kütüphaneler

* **Programlama Dili:** Python 3.x, SQL
* **Veri Analizi & Manipülasyon:** Pandas, NumPy
* **Veri Görselleştirme:** Matplotlib, Seaborn, Plotly
* **Geliştirme Ortamları:** Jupyter Notebook, VS Code, Google Colab
* **Veritabanı & Sorgulama:** PostgreSQL / MySQL, SQLite
